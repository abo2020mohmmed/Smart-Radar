# WinImageStudio

تطبيق WPF عربي لتخصيص صور Windows، مبني على .NET 10 وDISM وأدوات Windows الرسمية. هذا مشروع هندسي أولي قابل للبناء؛ ليس نسخة مطابقة لـNTLite، ولم يُعتمد للإنتاج؛ تشمل CI اختبارات Windows محددة ولا تشمل تثبيت نسخة Windows معدلة كاملة. لا توجد ضمانات بانعدام الأخطاء أو الثغرات.

## Lite 0.7.0 وFull 0.6.1

تتوفر نسخة مستقلة مبسطة: WinImageStudio-Lite-Setup-0.7.0-x64.exe. اختر ISO، ثم الإصدار، ثم التالي لبدء التخفيف والحفظ والضغط وبناء ISO تلقائيًا. تقبل بيانات Windows 10/11 Client الأصلية، بما فيها Home وN وEducation وEnterprise وLTSC، دون فرض Pro. لا تتضمن Lite مسار تخصيص يدوي أو خيارات ضغط متعددة. المصدر الأصلي محفوظ، ويستخدم الناتج اسمًا جديدًا.

تبقى الطباعة والمتجر واللغات العربية والإنجليزية الموجودة ولغة الأساس اللازمة محمية. ما كان مفقودًا أصلًا أو محميًا من الإزالة يظهر في التقرير؛ لا تُضاف حزم لغات أو متجر غير موجودة من تلقاء نفسها، ولا تُستخدم تجاوزات ملكية/CBS لحذف Defender المحمي. ضغط ESD مفعّل دائمًا في Lite، وADK المرفق يُجهز عند الحاجة وقد يلزم الإنترنت.

النسخة الكاملة مستقلة باسم WinImageStudio-Setup-0.6.1-x64.exe، وتتضمن تصحيح تشغيل البرنامج بعد إنهاء التثبيت بصلاحية المثبت (خطأ 740)، دون تعطيل UAC. البرنامجان يحفظان المشاريع خارج نطاق إزالة ملفات التطبيق. يمكن العودة لمشروع Lite غير مكتمل من خيار المتابعة أو سجل آخر مشروع؛ الجلسة المتعثرة تتطلب استعادة صريحة لأنها تتجاهل التعديلات غير المحفوظة.

الاختبارات تستخدم صورًا تجريبية صغيرة وبدائل للمحرك عند اختبار التسلسل الكامل. لا يوجد ISO كامل لـWindows داخل المستودع أو CI، ولا شهادة بسلامة كل إصدار/بناء أو إقلاع النتيجة. اختبر ISO في جهاز افتراضي.

## جديد في 0.6.0: ملف تثبيت EXE مع ADK المرفق

نزّل ملف WinImageStudio-Setup-0.6.0-x64.exe من آخر إصدار ناجح في Releases، وشغّله ثم اتبع التالي. المثبت ذاتي الاحتواء، وينشئ اختصارات سطح المكتب وقائمة ابدأ. يغلق المستخدم النسخة القديمة قبل التثبيت أو الترقية؛ لا تُغلق جلسة مركبة بالتجاهل لمجرد التحديث.

تتضمن الحزمة adksetup.exe المرفق نفسه، مع تحقق ثابت من حجمه وSHA-256 وتوقيع Microsoft. خيار تجهيز ADK يثبت Deployment Tools فقط إن لم تكن جاهزة، وقد يحتاج الإنترنت لتنزيل مكونات إضافية. الأدوات تبقى مشتركة على جهاز التحرير، ولا تدخل صورة Windows المعدلة. تسري شروط Microsoft على ملفها الأصلي، وليس ترخيص المشروع MIT.

إلغاء تثبيت WinImageStudio يزيل الملفات والاختصارات التي سجلها المثبت، ويبقي المشاريع وملفات ISO والتقارير وADK. لا توجد أوامر إزالة متكررة لمجلدات المستخدم أو تنظيف عام لصور Windows المركبة.

بناء المثبت على Windows: انشر التطبيق ذاتيًا بواسطة build.ps1 -Publish ثم شغّل installer/build-installer.ps1 مع توفر Inno Setup 6 حديث أو أحدث. يبني CI الحزمة ويفحص التثبيت والترقية والإزالة قبل إصدارها.

## جديد في 0.5.0: ضغط نهائي وفحص البرامج وإعداد ADK

يعاد تصدير الصورة النهائية إلى ESD بضغط recovery افتراضيًا بدل نسخ WIM المعدل كما هو. يمكن اختيار WIM بضغط max، ويعاد تصديره أيضًا إلى ملف جديد لاستبعاد البيانات غير المرجعية. قد تختلف النتائج حسب مصدر Windows والتغييرات؛ الحجم وحده لا يثبت إزالة البرامج.

صفحة الإخراج تتضمن زر تنزيل مثبت ADK الرسمي والتحقق من توقيعه وتثبيت Deployment Tools فقط، ثم تحديد oscdimg تلقائيًا. يحتاج اتصال إنترنت وتسري [شروط Microsoft ADK](https://learn.microsoft.com/windows-hardware/get-started/adk-install). الأدوات تثبت على جهاز التحرير ولا تدخل صورة Windows المعدلة.

صفحة النتيجة تعرض خيار إعادة البناء بضغط أعلى إلى اسم جديد، وخيار فحص صورة المشروع المحفوظة وإخراج HTML/JSON بقوائم Appx وWin32 المسجلة في HKLM وملفات التثبيت المضافة والميزات والخدمات واللغات. يُلغى تركيب جلسة الفحص دون commit. هذا جرد غير متصل وليس فحص أمان/إقلاع، ولا يضمن اكتشاف البرامج المحمولة وبرامج جميع المستخدمين. يفحص WIM المحفوظ للمشروع؛ إن تغير المشروع بعد بناء ISO فأعد البناء لمطابقته.

ملف iso-build-summary.json يحوي أحجام المصدر والناتج بالبايت، وimage-audit.json يحوي جرد المحتويات. لا تُحذف النسخة السابقة عند إعادة البناء.

## المعالج المتسلسل

صفحة واحدة لكل مرحلة، وزر إجراء ثابت أسفل النافذة. زر **التالي — حفظ الصورة** ينفذ الحفظ وإلغاء التركيب فعلًا، ثم يفتح الإخراج؛ لم يعد مجرد تنقل إلى القسم نفسه. السجل التفصيلي والخيارات المتقدمة مطوية افتراضيًا.

## المتطلبات

- Windows 10/11 x64 مدعوم ومحدّث، ومساحة NTFS محلية كافية للصورة المفكوكة والمركبة ونسخة ISO. يفضّل توفير 30–60 GB أو أكثر وفق المصدر. صور أحدث قد تتطلب أدوات DISM/ADK متوافقة.
- .NET 10 SDK للبناء؛ النسخة المنشورة ذاتية الاحتواء لا تتطلب تثبيت runtime مستقل.
- صلاحيات Administrator؛ التطبيق يطلب UAC عبر manifest.
- Windows PowerShell 5.1 وDISM (موجودان في Windows).
- Windows ADK Deployment Tools وoscdimg.exe لبناء ISO. اضبط مساره في الواجهة.
- wimlib-imagex.exe من توزيعة wimlib الأصلية لجمع SWM فقط. لا يُضمَّن مع المشروع؛ راجع رخصته قبل توزيعه.
- استخدم وسائط Windows التي تملك حق استخدامها. لا تُضمّن صور Windows أو أدوات Microsoft في هذا المستودع.

## البناء

```powershell
.\build.ps1
.\build.ps1 -Publish
```

الناتج: `artifacts/win-x64/WinImageStudio.exe`. احتفظ بمجلد Scripts بجانب التطبيق. يتطلب أول restore اتصالًا بـNuGet للحصول على حزم استهداف Windows. يمكن تشغيل الاختبارات الأساسية على Linux:

```bash
dotnet run --project tests/WinImageStudio.Tests/WinImageStudio.Tests.csproj -c Release
```

## الاستخدام

1. اختر التخفيف القوي أو التخصيص اليدوي، وملف Windows ومجلد العمل، ثم **التالي — قراءة المصدر**. اختر wimlib من القسم المتقدم إذا كان المصدر SWM.
2. اختر الإصدار ثم **التالي — تجهيز الصورة**. يُنسخ الإصدار ويُركب وتُحلل خطة التخفيف تلقائيًا. المسار اليدوي يعرض قوائم المكونات.
3. راجع التعديلات، ثم **التالي — مراجعة الخطة**. إذا غيّرت خيارات التخفيف، اضغط التالي لإعادة التحليل ثم راجع النتيجة الجديدة واضغط التالي مرة أخرى.
4. راجع الخطة وحدد الموافقة، ثم **التالي — تطبيق التعديلات**. راجع النتيجة والعناصر المتبقية، ثم **التالي — حفظ الصورة**؛ ينفذ ذلك commit وإلغاء التركيب.
5. في صفحة الإخراج حدد اسم ISO جديدًا وoscdimg.exe من Windows ADK، ثم **التالي — إنشاء ISO**. بعد اكتماله تظهر صفحة النتيجة مع زر لفتح مجلد الملف.

المصدر WIM/ESD/SWM دون وسائط ISO كاملة ينتهي بصورة WIM محفوظة، وتوضح الواجهة ذلك. لا يُنشأ ISO وهمي. افتح مشروعًا سابقًا من صفحة البداية، أو شغّل `WinImageStudio.exe --project "C:\path\project"` للمتابعة من حالته المسجلة. الصورة المطبقة تنتقل مباشرة إلى صفحة التقرير والحفظ.

زر السابق للتنقل قبل التطبيق؛ لا يعكس تغييرات مطبقة. الاستعادة مخصصة للفشل المسجل وتتجاهل تعديلات جلسة التركيب غير المحفوظة؛ لا تستخدمها للانتقال بعد النجاح. اختبر النسخة النهائية في جهاز افتراضي.

## القدرات الفعلية والحدود

| الوظيفة | التنفيذ |
|---|---|
| قراءة WIM/ESD متعدد الإصدارات | Get-WindowsImage وتصدير الإصدار المختار بـDISM |
| ISO | تركيب المصدر مؤقتًا، نسخه، وفك تركيبه إذا ركّبه التطبيق |
| SWM | جمع الأجزاء بواسطة wimlib ثم نفس مسار WIM |
| ميزات Windows | تعداد وتفعيل وتعطيل الميزات التي يدعمها DISM |
| مكونات/حزم | تعداد وإزالة الحزم التي يسمح DISM بإزالتها؛ لا حذف يدويًا لملفات WinSxS ولا محرك NTLite الخاص لإزالة مكونات محمية |
| تحديثات ولغات | دمج CAB/MSU عبر DISM؛ ترتيب المتطلبات والملاءمة مسؤولية المشغّل والأداة |
| Drivers | إضافة INF مع ملفات التعريف المجاورة وإزالة oem*.inf؛ لا ForceUnsigned |
| تطبيقات Windows | تعداد وإزالة التطبيقات provisioned؛ ليست إدارة كل تطبيقات جميع حسابات المستخدمين |
| خدمات | تعديل Start في SYSTEM غير المتصل؛ رفض خدمات boot/system-start وتعريفات kernel |
| Registry | SOFTWARE/SYSTEM، أنواع String/ExpandString/DWORD/QWORD/MultiString/Binary؛ CurrentControlSet يُحوّل للقيمة الصحيحة |
| Silent installers | تهيئة EXE/MSI عبر SetupComplete، بمفاتيح يحددها المستخدم، دون تنفيذها على المضيف |
| Unattend | اسم جهاز/لغة/لوحة مفاتيح/منطقة زمنية ومعمارية؛ لا كلمات مرور ولا تجاوز متطلبات Windows |
| ISO boot | BIOS وUEFI عند وجود ملفات الإقلاع في الوسائط |
| Presets | خطة JSON قابلة للمراجعة، وسجل مشروع دائم |

ملف Autounattend.xml يُحفظ في جذر المشروع ويُنسخ إلى جذر وسائط ISO إن كانت موجودة. مع WIM منفرد انقل XML بنفسك إلى وسائط التثبيت. يلزم أن تكون اللغة مثبتة في الصورة؛ تحقق من Windows time-zone ID. لا يُطبّق XML على جهاز التحرير.

SetupComplete لا يعمل في جميع مسارات/تراخيص التثبيت، وقد يُعطّل مع بعض مفاتيح OEM؛ اختبر السيناريو الفعلي. التطبيق لا يكتشف المفاتيح الصامتة تلقائيًا، ولا يتحقق من سلامة الناشر أو hash ملف التثبيت. يسمح لمعاملات التثبيت بحروف ASCII فقط ويرفض رموز shell الخطرة؛ استخدم حزمًا موثوقة. عند وجود SetupComplete.cmd من أداة أخرى يرفض استبداله. يحتفظ ببرامج التثبيت وسجل نتائجها داخل Windows الناتج.

## التعافي وعدم فقد المصدر

قبل تعديل الصورة أو تركيب hive يُسجل المشروع الحالة RecoveryRequired ذريًا في project.json، ثم يُزيلها عند نجاح الخطوة. عند انقطاع التطبيق أو فشل خطوة، افتح نفس المشروع واستخدم الاستعادة. الاستعادة تفك hives التابعة لمعرف هذا المشروع فقط، وتعيد تركيب mount المسجل عند الحاجة، ثم تتجاهل تعديلات الجلسة غير المحفوظة. لا تستخدم تنظيفًا عامًا لكل mounts الخاصة بالنظام.

الإلغاء لا يقتل DISM/reg/oscdimg أثناء التشغيل؛ يُلاحظ بين الخطوات. قد يستغرق اكتمال الأداة وقتًا طويلًا. لا يوجد rollback لكل خطة بعد كل خطوة: التراجع قبل commit يكون بتجاهل جلسة الصورة كاملة. عند فشل استيراد/استخراج صورة قبل تركيبها قد يلزم إنشاء مشروع جديد؛ لا تحذف ملفات مشروع يحتوي mount نشطًا.

السجل العام في `%LOCALAPPDATA%\WinImageStudio\Logs`، وسجلات DISM في `logs` داخل المشروع. لا تضع كلمات مرور أو مفاتيح منتج في الخطة أو معاملات التثبيت أو قيم السجل، لأنها تُحفظ كنص.

## الاعتماد قبل الإنتاج

اختبر على Windows حقيقي: UAC، انقطاع التطبيق، DISM incompatibility، امتلاء القرص، ملفات طويلة، CAB/MSU مع dependencies، تعريفات موقعة، reload للخطط، registry unload، SetupComplete، BIOS/UEFI boot، وتثبيت Windows كاملًا. لم تثبت الاختبارات المنطقية أن صورة Windows الناتجة قابلة للإقلاع. الواجهة تعمل بصلاحيات مرتفعة؛ افحص/وقّع الملفات وسلسلة التوزيع قبل استخدامها في مؤسسة. ملف boot.wim داخل ISO لا يُعدّل تلقائيًا؛ إضافة تعريف إلى install.wim لا تضمن توفره داخل Windows PE. لا توجد محاكاة لقاعدة اعتماديات NTLite الخاصة، ولا توزيع شبكي أو تحرير نظام حي أو تكامل كامل لكل مخططات القرص وحسابات unattended.

لا يعمل المشروع على Windows النظام الحي (`/Online`) ولا يوفر محاكاة كاملة لكل مزايا NTLite.
