# وضع التخفيف القوي — 0.3.0

هذا الوضع يولّد خطة من مكونات الصورة المركبة فعلًا. لا يعمل على Windows الحي، ولا يحمّل Ghost Spectre أو أي ISO معدل. ليس محاكاة كاملة لمحرك إزالة المكونات الخاص بـNTLite.

## التشغيل

1. استخدم صورة Windows 10/11 Pro العادية الرسمية، وانسخ الإصدار المختار إلى المشروع ثم ركّبه.
2. افتح الخطوة **③ · التخفيف القوي**، ثم **تحليل الصورة وإنشاء خطة التخفيف**.
3. راجع الأهداف وأسباب اختيارها والملاحظات أسفل القائمة. التحليل لا يحذف العناصر.
4. اضغط **إضافة التخفيف إلى خطة التطبيق**، وراجع الخطة في الخطوة ④ ثم طبّقها.
5. اقرأ تقرير النتيجة، ثم احفظ الصورة وألغِ تركيبها. مشروع ISO يدعم بناء ملف ISO جديد بعد الحفظ.

تعاد قراءة هوية الصورة والخطة قبل التطبيق؛ لا يُقبل اسم مثل Windows Pro وحده. الهوية المقبولة `Professional` مع نوع تثبيت Client ورقم بناء Windows 10 أو أحدث. تُرفض Home وPro N وPro Education وPro for Workstations وEnterprise وServer. يحتاج الوضع إلى وجود حزمة Microsoft Store وخدمة الطباعة في المصدر.

## ما يختاره

- حزم Xbox وGaming App وGaming Services وGame Bar المعروفة إذا كانت مجهزة وقابلة للإزالة، وتطبيقات إضافية من قائمة أسماء محددة مثل Cortana وGetHelp والتطبيقات الترويجية؛ لا wildcard لحذف كل تطبيقات Microsoft.
- OneDrive المجهز، وقيم تشغيله المخصصة، وملفا الإعداد المعروفان داخل System32/SysWOW64. لا يحذف مجلدات المستخدمين أو ملفاتهم السحابية. تُسجل الملفات المحمية أو تثبيتات Win32 التي لم تُحذف في تقرير التنفيذ.
- بعض الميزات القديمة/الاختيارية الموجودة والمفعلة، وبعض خدمات التشخيص/التجزئة/Xbox المحددة فقط. خدمات وتعريفات boot/kernel خارج القائمة.
- حزم اللغة الكاملة وLXP وميزات اللغة FOD الأجنبية المعروفة، دون الخطوط المشتركة، وبترتيب LXP ثم ميزات اللغة ثم الحزمة. العربية والإنجليزية بكل متغيراتهما محفوظتان، ولغة الأساس محفوظة أيضًا. عند جهل لغة الأساس أو وجود servicing معلّق يتوقف اختيار إزالة اللغات.
- سياسات لتقليل اقتراحات التطبيقات وإيقاف Game DVR ووضع مستوى التشخيص الأساسي المدعوم في Pro ومنع مزامنة OneDrive؛ قد تختلف استجابة السياسات حسب إصدار Windows.

## ما يبقى

Microsoft Store واعتماديات الشراء وApp Installer وأطر التطبيقات، والطباعة وخدماتها، والتعريفات و.NET وDirectX وMedia Foundation ومكونات الصوت والشبكة، وWindows Update وUAC والجدار الناري والاسترداد ليست ضمن الحذف التلقائي. يعيد الوضع تفعيل أساس الطباعة المتاح وخدمة Spooler المعطلة إذا كان ذلك ممكنًا. وجود هذه المكونات لا يضمن عمل طابعة بعينها دون تعريفها.

إزالة Xbox/Gaming Services قد تعطل ألعابًا تحتاجهما حتى لو بقي المتجر. لا نغيّر HPET أو ملف الذاكرة الافتراضية ولا نحذف مخزن WinSxS عشوائيًا. لا يوجد ضمان بمقدار معين من RAM أو مساحة الصورة أو زيادة FPS.

## Defender: حد تقني ظاهر في التقرير

يقرأ الوضع بيانات الحزم المخصصة لـDefender. الحزمة الدائمة أو المجهولة القابلية للإزالة لا تدخل خطة الحذف. لا تُغيّر ملكية ملفات النظام أو Owners/Visibility الخاصة بحزم CBS، ولا تُحذف ملفات عشوائيًا لمجرد احتواء اسمها على Defender. لوحة Windows Security ومكونات الجدار الناري المشتركة محفوظة.

في كثير من صور Pro سيبقى Defender مدمجًا ومحميًا، وسيقول التقرير ذلك بوضوح. خيار الفحص لا يَعِد بإزالته بالكامل، ولا يستبدل الإزالة بتعطيل مخفي أو تعديلات على حماية جهاز التحرير. القابلية المقدرة من manifest ليست ضمانًا؛ DISM هو من يقبل/يرفض العملية. بعد التطبيق يُفحص وجود محركه/خدمته وتُعرض النتيجة.

توثّق مايكروسوفت أوامر إزالة ميزة Defender على Windows Server تحديدًا، وتوضح اختلاف سلوك Windows 10/11 عند تثبيت مضاد فيروسات آخر: [توثيق التوافق الرسمي](https://learn.microsoft.com/en-us/defender-endpoint/microsoft-defender-antivirus-compatibility).

## اللغات

الوضع يحافظ على العربية والإنجليزية المثبتتين، لكنه لا يصنع ملفات لغة غير موجودة. إذا كانت العربية أو الإنجليزية غير مثبتة فستظهر ملاحظة؛ أضف حزم اللغة الرسمية المطابقة للبناء والمعمارية من قسم الدمج، ثم أعد التحليل. إذا كانت لغة أساس الصورة فرنسية مثلًا فستبقى؛ اختر مصدرًا أساسه العربية أو الإنجليزية للحصول على هذا الهدف من البداية.

قد تبقى موارد مشتركة أو حزم محمية. لا يحذف الوضع مجلدات MUI من System32 ولا كل مورد لغة داخل كل تطبيق. [إدارة اللغات رسميًا ومتطلبات إزالة الحزم](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/add-language-packs-to-windows?view=windows-11).

## التقارير والاختبار

يُحفظ `aggressive-report.json` قبل التنفيذ و`aggressive-after.txt` بعده داخل المشروع. الخطة قابلة للتصدير JSON. يُمنع خلط خطة الوضع مع حذف المتجر أو أطره أو تعطيل الطباعة والخدمات المحفوظة. عند فشل servicing استخدم التعافي/تجاهل جلسة الصورة وفق حالة المشروع.

اختبارات الاختيار والحماية تستخدم قوائم مكونات اصطناعية. توجد اختبارات Windows PowerShell لقراءة manifests، ومع صلاحيات المسؤول اختبار تحميل/قراءة/تفريغ hives اصطناعية معزولة. لا تعادل هذه الاختبارات تعديل ISO حقيقيًا ثم تثبيته والإقلاع منه واختبار الطباعة والمتجر والألعاب. يلزم إجراء ذلك في VM قبل اعتماد الصورة.
