# WinImageStudio 0.5.0 — نسخة Windows

مشروع WPF عربي لتخصيص صور Windows، مستقل عن ملفات Smart-Radar الأخرى.

## التنزيل

افتح [بناء Windows](https://github.com/abo2020mohmmed/Smart-Radar/actions/workflows/winimage-studio.yml)، ثم آخر تشغيل ناجح، ونزّل WinImageStudio-windows-x64 من Artifacts بعد تسجيل الدخول. فك الضغط كاملًا وشغّل Start-WinImageStudio.cmd. الحزمة ذاتية الاحتواء ولا تحتاج تثبيت .NET. تُحفظ حزم Actions مدة 30 يومًا.

## واجهة متسلسلة

اختر المصدر والمسار، ثم اضغط التالي لتجهيز الإصدار. راجع التعديلات، ثم التالي لمراجعة الخطة. وافق وطبّق، ثم اقرأ التقرير واضغط التالي لحفظ الصورة فعلًا. في صفحة الإخراج حدد اسم ISO وأداة oscdimg من Windows ADK، ثم التالي لإنشاء ISO. زر الإجراء ثابت أسفل النافذة؛ لا حاجة للبحث بين التبويبات. السجل والخيارات المتقدمة مطوية افتراضيًا.

فتح مشروع مطبق سابقًا ينقلك مباشرة إلى صفحة الحفظ. المصادر دون وسائط ISO كاملة تنتهي بصورة WIM محفوظة ويُوضح ذلك. التخفيف القوي لـWindows Pro يحافظ على المتجر والطباعة والعربية والإنجليزية المثبتتين؛ Defender وOneDrive المحميان قد يبقيان ويُظهرهما التقرير. لا يدعي البرنامج إزالتهما بالكامل.

[الدليل العربي](README.ar.md) · [سجل التغييرات](docs/CHANGELOG.md) · [حدود التخفيف](docs/STRONG-PRESET.ar.md)

إصدار هندسي، وليس مطابقًا لكل قدرات NTLite. اختبارات آلية تشمل WIM تجريبيًا ولا تثبت نجاح تثبيت نسخة Windows كاملة؛ اختبر ISO النهائي في جهاز افتراضي.

## ضغط ESD وفحص البرامج وإعداد ADK

تعاد تصدير الصورة إلى install.esd بضغط recovery افتراضيًا؛ يمكن اختيار WIM بضغط max. من النتيجة يمكن إعادة إنشاء ISO باسم جديد دون إعادة التخفيف، مع إبقاء ISO السابق. يظهر حجم الأصل والناتج، ولا يُضمن حجم نهائي محدد.

زر إعداد ADK في صفحة الإخراج ينزل مثبت Microsoft الرسمي ويتحقق من توقيعه ثم يثبت Deployment Tools فقط ويحدد oscdimg تلقائيًا. يحتاج إنترنت وتسري شروط Microsoft؛ لا تضاف أدوات ADK لصورة Windows المعدلة.

زر فحص الصورة في النتيجة يولد image-audit.html وimage-audit.json لجرد صورة WIM المحفوظة للمشروع: Appx، برامج Win32 المسجلة في HKLM، ملفات التثبيت المضافة، الميزات والحزم والتعريفات والخدمات واللغات. ليس فحصًا أمنيًا أو اختبار إقلاع ولا يكتشف كل البرامج المحمولة أو برامج جميع المستخدمين.
