# WinImageStudio 0.6.0 — Windows EXE installer

ملف تثبيت EXE واحد يتضمن البرنامج ذاتيًا وملف adksetup.exe المرفق نفسه. نزّل WinImageStudio-Setup-0.6.0-x64.exe من [الإصدارات](https://github.com/abo2020mohmmed/Smart-Radar/releases)، وشغّله ثم اتبع التالي. ينشئ اختصارات سطح المكتب وقائمة ابدأ.

يفحص المثبت بصمة المرفق وتوقيع Microsoft قبل تشغيله، ويجهز Deployment Tools فقط عند الحاجة. قد يحتاج الإنترنت لتنزيل مكونات ADK؛ ملف bootstrapper مضمن، وليس كامل مكونات ADK دون اتصال. تسري شروط Microsoft على مكوناتها. البرنامج لنسخ Windows 10/11 x64 المحدثة، ويحتاج صلاحية المسؤول.

أغلق النسخة القديمة قبل التثبيت، ثم افتح مشروعك السابق من البرنامج الجديد. الترقية وإلغاء التثبيت يبقيان المشاريع وملفات ISO والتقارير وأدوات Microsoft ADK المشتركة. يحتوي المثبت على ملفات التطبيق فقط ولا يغير صور Windows عند تثبيت التطبيق.

يشمل البرنامج المعالج المتسلسل، تخفيف Pro، ضغط ESD، إعداد ISO، وفحص برامج الصورة إلى HTML/JSON. قد تبقى ملفات Defender وOneDrive المحمية ويُظهرها التقرير. اختبر ISO النهائي في جهاز افتراضي.
