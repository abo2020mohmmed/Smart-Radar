# WinImageStudio Lite 0.7.0 + Full 0.6.1

## تنزيل نسخة Lite المبسطة

من [الإصدارات](https://github.com/abo2020mohmmed/Smart-Radar/releases) نزّل **WinImageStudio-Lite-Setup-0.7.0-x64.exe**. ملف تثبيت واحد يتضمن نفس مثبت ADK المرفق مع التحقق من بصمته وتوقيع Microsoft. قد يحتاج الإنترنت لتنزيل مكونات Deployment Tools.

اختر ISO الأصلي، ثم أي إصدار Windows 10/11 Client موجود مثل Home أو Pro أو Education أو Enterprise أو LTSC. اضغط التالي لبدء جميع خطوات التجهيز والتحليل والتخفيف والحفظ وضغط ESD وبناء ISO. لا يوجد مسار يدوي في Lite. يُحفظ الناتج باسم جديد مع تقرير بما بقي، ويبقى المصدر محفوظًا. فشل أي خطوة يوقف التسلسل ولا يُعلن اكتمال الملف. اختبر ISO النهائي في جهاز افتراضي.

المتجر والطباعة الموجودة والعربية والإنجليزية ولغة الأساس اللازمة محمية. المكونات المفقودة من المصدر لا تضاف تلقائيًا، وDefender وOneDrive المحميان قد يبقيان. الصور Server/WinPE والقديمة خارج نطاق Lite.

## النسخة الكاملة

**WinImageStudio-Setup-0.6.1-x64.exe** يحتفظ بالمعالج والتخصيص اليدوي، ويصحح تشغيل التطبيق بعد إنهاء التثبيت بصلاحية المثبت بدل الخطأ 740. يعمل Lite مستقلاً عنها، وتبقى المشاريع وISO وADK المشتركة بعد إلغاء تثبيت أي منهما.
