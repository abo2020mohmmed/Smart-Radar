WinImageStudio 0.6.1 — تثبيت البرنامج

يتضمن هذا المثبت نفس ملف adksetup.exe المرفق، ويجري التحقق من بصمته وتوقيع Microsoft قبل تشغيله.
أدوات ADK مطلوبة لبناء ISO. يمكن تجهيز Deployment Tools أثناء تثبيت البرنامج أو لاحقًا من داخله. قد يحتاج مثبت ADK إلى الإنترنت لتنزيل المكونات؛ وجود adksetup.exe لا يعني أن جميع مكونات ADK مضمنة دون اتصال.

أغلق WinImageStudio القديم قبل المتابعة. لا تحذف مجلدات مشروع يحتوي صورة Windows مركبة.
التثبيت لا يغير صور Windows أو ملفات ISO الحالية. إزالة البرنامج تزيل ملفات التطبيق واختصاراته فقط؛ تبقى مشاريعك وتقاريرك وملفات ISO، وتبقى أدوات Microsoft ADK المشتركة مع البرامج الأخرى.

WinImageStudio مشروع هندسي مفتوح المصدر. اختبر ISO المعدل في جهاز افتراضي قبل استخدامه. مثبت Microsoft المرفق يخضع لشروط Microsoft الأصلية، وليس لترخيص المشروع MIT.
