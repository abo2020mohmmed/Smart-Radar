WinImageStudio 0.6.0 — نسخة التثبيت
شغّل WinImageStudio-Setup-0.6.0-x64.exe، ثم التالي واختر الاختصارات وتجهيز ADK حسب حاجتك.
المثبت يحتوي adksetup.exe المرفق نفسه. يتحقق من SHA-256 وتوقيع Microsoft قبل تشغيله، ويجهز Deployment Tools فقط. قد يحتاج الإنترنت لتنزيل مكونات ADK. إذا كانت الأداة جاهزة فلا تعاد تثبيتها.
أغلق WinImageStudio القديم قبل التثبيت؛ تبقى مشاريعك محفوظة. شغّل البرنامج من اختصار سطح المكتب أو قائمة ابدأ، وافتح مشروعك السابق من صفحة البداية.
إزالة البرنامج تبقي المشاريع وISO والتقارير وأدوات Microsoft ADK المشتركة. لا تحذف مشروعًا يحتوي صورة مركبة.

فك ضغط الحزمة كاملة إلى مجلد جديد وشغّل Start-WinImageStudio.cmd بصلاحية المسؤول.

زر التالي ثابت أسفل النافذة وينفذ الإجراء المكتوب عليه:
1. اختر المسار وملف Windows ومجلد العمل، ثم التالي لقراءة المصدر.
2. اختر Pro ثم التالي لتجهيز الصورة وتحليل التخفيف تلقائيًا.
3. راجع التعديلات المقترحة، ثم التالي لعرض خطة التطبيق. تغيير خيارات التخفيف يتطلب التالي لإعادة التحليل ومراجعة النتيجة الجديدة.
4. راجع الخطة وحدد الموافقة ثم التالي لتطبيقها. اقرأ تقرير المتبقي، ثم اضغط التالي مرة أخرى لحفظ الصورة وإلغاء تركيبها فعليًا.
5. اختر مكان ISO وأداة oscdimg.exe من Windows ADK في الصفحة نفسها، ثم التالي لإنشاء ISO.
تظهر صفحة النتيجة بعد اكتمال الإنشاء. زر فتح مجلد النتيجة يفتح مكان الملف.

إذا فتحت مشروعًا مطبقًا سابقًا، سيظهر تقريره وزر التالي — حفظ الصورة مباشرة. لا تعِد التحليل ولا تستخدم الاستعادة لمجرد بقاء ملفات محمية.
المصادر WIM/ESD/SWM دون وسائط ISO كاملة تنتهي بصورة WIM محفوظة؛ يُوضح ذلك ولا يُدعى إنشاء ISO.
السجل التفصيلي مطوي في أسفل النافذة. الإعدادات الاختيارية داخل أقسام متقدمة في الصفحة المناسبة.
الاستعادة مخصصة للجلسات المتعثرة وتتجاهل التعديلات غير المحفوظة. لا تحذف مجلدًا يحتوي على صورة مركبة.
قد تبقى ملفات OneDrive أو Defender المحمية؛ التقرير يوضح ذلك. اختبر الناتج في جهاز افتراضي قبل تثبيته.

إضافات 0.5.0:
- في صفحة الإخراج اضغط تنزيل وتثبيت أدوات ISO تلقائيًا إذا لم تكن oscdimg مثبتة. يتحقق البرنامج من توقيع مثبت Microsoft ويثبت Deployment Tools على جهازك فقط. يحتاج إنترنت، وتسري شروط Microsoft ADK.
- ضغط ESD الأعلى مفعّل افتراضيًا. يعيد تصدير الصورة إلى ملف جديد قبل إنشاء ISO، ولا يضمن حجمًا محددًا. WIM يظل متاحًا بإلغاء الخيار.
- من صفحة النتيجة افتح مشروعك المحفوظ واضغط إعادة إنشاء ISO بضغط أعلى، ثم التالي. يُستخدم اسم جديد ويبقى ISO السابق محفوظًا.
- اضغط فحص الصورة وعرض البرامج، ثم فتح تقرير البرامج. يفحص صورة WIM المحفوظة للمشروع دون حفظ تعديلات الفحص، ويولد image-audit.html وimage-audit.json داخل مجلد المشروع. أرفق JSON إذا أردت مراجعة البرامج المكتشفة. التقرير لا يساوي فحصًا أمنيًا أو اختبار إقلاع، ولا يكتشف كل التطبيقات المحمولة أو برامج كل المستخدمين.
